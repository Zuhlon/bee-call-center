# 🐝 Пчелиный колл-центр | Bee Call Center

Мобильная игра в стиле Apple Arcade, где вы управляете пчелиным колл-центром. Вместо разговоров пчёлы общаются танцами! 🎮

## 🎮 Об игре

Вы управляете колл-центром в пчелином улье. Пчёлы-операторы принимают "танцевальные звонки" от клиентов из соседних полянок, лесов и ульев. Но берегитесь шершней из дубовой рощи — они нападают и крадут ваших пчёл!

### Цель
Достичь идеального баланса: **количество операторов = баланс очков**

### Управление
| Кнопка | Действие | Эффект |
|--------|----------|--------|
| 🐝 **НАНЯТЬ** | Нанять новую пчелу-оператора | −1⭐ баланс |
| 📞 **ОТВЕТИТЬ** | Принять входящий танец | +1⭐ баланс |

### Механика
- 🌸 **Клиенты** — приходят каждые 2 секунды (полянка, лес, улей)
- ⚠️ **Шершни** — атакуют случайно (20% шанс), крадут 1-2 пчёл на 8 секунд
- 🏆 **Достижение** — разблокируется при балансе = операторы

## ✨ Особенности

- 🎨 **Дизайн Apple Arcade** — тёмная тема, glassmorphism, плавные анимации
- 📱 **Mobile-first** — оптимизировано для iPhone 12 mini (375px) и выше
- 🎭 **Анимации** — плавающие пчёлы, тряска при захвате, пульсация предупреждений
- 🌐 **PWA-ready** — работает в браузере на любом устройстве

## 🚀 Запуск

```bash
# Установка зависимостей
bun install

# Режим разработки
bun run dev

# Сборка для продакшена
bun run build

# Запуск продакшен-сервера
bun start
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.
